Initial fully codified working draft.

- Defines stable `ASSESS` and `SPECIFY` profiles.
- Defines cross-cutting `TRANSFORM` conformance.
- Defines five calibrated-force axes.
- Normalizes WEP output to one coherent canonical vocabulary row.
- Defines P0/P1/P2 preservation classes and retention contracts.
- Defines 30 initial deterministic and semantic rules.
- Defines policy, finding, adjudication, preservation, receipt, corpus, and capability objects.
- Includes machine-readable schemas, examples, and package validation.
- Separates normative rule state from detector evidence authority.
- Adds standalone policy-exception and package-manifest schemas plus cross-object validation.
